Cookie Login
How to get cookies
On desktop Chrome/Firefox:

1. Go to tiktok.com and log in normally
2. Install the extension Cookie-Editor (Chrome / Firefox)
3. Click the extension icon while on TikTok
4. Click Export → Export as JSON
5. Copy the JSON and paste it into the Cookie Login tab

Cookies expire after a while — if it stops working, re-export them.
